# project-3
Phishing  Awareness Analysis


## Description
This project was developed as part of my coursework.
The project analyzes sample emails or messages to identify possible phishing attempts.

## Objectives
- Understand the basic concepts of phishing attacks
- Identify suspicious links and keywords
- Detect red flags in phishing messages
- Explain why a message may be unsafe
- Improve cybersecurity awareness

## Technologies Used
- Python
- GitHub

## How to Run
1. Download or clone the repository.
2. Open the Python source code.
3. Run the program.
4. Enter an email or message for analysis.
5. View the phishing analysis results.
